Card options

Load one resource, then choose the card type in the Home Assistant dashboard editor.

Detailed

ClearSpace Tasks

Main task list card with due dates, status, add button, and task completion actions.

  • custom:clearspace-card
  • Best for a full task list
  • Shows source and freshness
Compact

ClearSpace Compact

A smaller card for a tight dashboard. Shows counts and the top tasks.

  • custom:clearspace-compact-card
  • Good for phone dashboards
  • Uses a slimmer layout
Board

ClearSpace Board

Grouped columns for overdue, today, upcoming, and done tasks.

  • custom:clearspace-board-card
  • Best for at-a-glance planning
  • Looks more like a task board
Stats

ClearSpace Stats

Shows counts only: open, due today, overdue, and done.

  • custom:clearspace-stats-card
  • Best for a clean summary row
  • Smallest and simplest option

How to install in Home Assistant

This is the exact setup flow most users need.

1) Add the resource

HACS → Frontend → Custom repositories
https://github.com/yusufyusufyusufyusuf/clearspace-card

Then download the ClearSpace card resource.

2) Add it to Lovelace

Settings → Dashboards → Resources → Add resource
URL: /local/clearspace-card.js
Type: JavaScript Module
If you use HACS, just install the resource once. The four card types appear after the browser refreshes.

Recommended configs

Task list card

type: custom:clearspace-card
entity: sensor.clearspace_tasks
title: ClearSpace Tasks
refresh_interval_seconds: 60
show_completed: true
max_items: 50
show_add_button: true

Board card

type: custom:clearspace-board-card
entity: sensor.clearspace_tasks
title: ClearSpace Board
refresh_interval_seconds: 60
show_completed: true
